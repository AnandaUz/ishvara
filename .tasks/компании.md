# Задача: Компании (Анализ гипотез по набору страниц) [ВЫПОЛНЕНО]

## Описание
Компания в контексте данной задачи — это гипотеза для анализа набора целевых страниц проекта.
Пользователь может создавать, редактировать и удалять компании для каждого проекта, привязывая к ним список адресов страниц. При выборе активной компании данные во всех вкладках фильтруются только по посетителям/событиям этих страниц.

## Выполненные требования
1. **Изоляция по проектам:** Список компаний привязан к `projectId` и автоматически перезагружается при смене проекта.
2. **Интерфейс выбора и настроек:**
   - Выпадающий список выбора активной компании в строке вкладок (`view-type-tabs-block`).
   - Кнопка редактирования `[ ✎ ]` рядом с селектором открывает окно управления.
3. **Управление компаниями (CRUD):**
   - Компонент `c-company-modal`: создание, редактирование и удаление компании.
   - Построчный ввод адресов страниц (поддержка относительных путей и полных URL).
4. **Сквозная фильтрация:**
   - «статистика»: графики тегов/ботов фильтруются по посетителям целевых страниц.
   - «активность»: список гостей фильтруется по наличию страниц компании (`pages: { $in: [...] }`).
   - «визиты на страницы» и «динамика страниц»: отображаются только страницы компании.
5. **Персистентность:**
   - Коллекция в MongoDB (модель `Company`).
   - Сохранение выбранной компании в `LocalPersistence` (`localStorage`).
